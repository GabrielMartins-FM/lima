Categorias de conteudo HTML5

Elementos de bloco

Ocupam toda a largura disponivel, exemplo: <div>, <p>, <h1>, <section>, <article>

Elementos de linha

Ocupam apenas o espaço necessario na linha, exemplo: <a>, <span>, <strong>, <em>, <img>

Regras importantes

Elementos de linha não devem conter elementos de bloco

Exemplo incorreto:

Texto

Exemplo correto:
Texto

Categorias de conteudo:

Metadata Content

São Informaçãoes de configurações do arquivo HTML

<title> : Informa o titulo da pagina.

<meta> : Definir codificação.

<link> e <style> : importar/anexar CSS.

<script> : importar/anexar comandos javascript.

Flow Content

Representa a maior parte dos elementos usados no body.

<div> : criar uma divisão generica, agrupar "pedaços" de codigo.

<p> : Criar paragrafo dentro da pagina.

<section> : agrupa conteudos que partilham do mesmo assunto/ideia.

<article> : conteudo independente e completo por si só (Faz sentido sozinho).

<img> : importar imagem, desenho, foto (Não precisa de tag de fechamento).

<form> : criar formularios, o usuario pode digitar dados e/ou enviar mensagem, fazer login.

Sectioning Content

Organizar grandes areas do documento

<section> : agrupa conteudos que partilham do mesmo assunto/ideia.

<article> : conteudo independente e completo por si só (faz sentido sozinho).

<aside> : serve para guardar um conteudo secundario/lateral (links relacionados, anuncios, biografia e etc).

<nav> : agrupar links de navegação.

Heading Content

h1,h2,h3,h4,h5 e h6: Adicionar titulos e subtitulos

<hgoup> : agrupar alementos de titulo, exemplo:

Aprenda HTML
SENAI Americana

Phrasing Content

Elementos que marcam textos ou partes de texto

<span> : Um bloco generico, não muda nada sozinho, porem pode aplicar CSS ou chamar funções/comportamento com javascript.

<a> : Criar um link para direcionar usuario para outra pagina, utilizando o atributo href. Exemplo: Clique para conhecer o Bitcoin

<strong> : serve para deixar uma parte do texto em Negrito.

<em> : serve para deixar uma parte do texto em italico.

<mark> : serve para adicionar um marcador em uma prate do texto.

<img> : importar imagem, desenho, foto (Não precisa de tag de fechamento).

Embedded Content

Utilizado para inserir um conteudo externo

<img> : importar imagem, desenho, foto (Não precisa de tag de fechamento).

<video> : adicionar um video(Pode mostrar botões de play e pause).

<canvas> : criar uma tela em branco que podera ser usada pelo javascriptp.

<svg> : vai desenhar graficos baseados em vetores.

<iframe> : colocar outra pagina inteira dentro do seu website (mutio usado para adicionar mapas e videos).

Interactive Content

Permite interações com o usuario

<a> : criar um link para direcionar o usuario para outra pagina, utilizando o atributo href.

<button> : cria botão. exemplo:

<input> : usado para receber dados do usuario, Dentre os dados aceitos estão:

type = "text": campo de texto curto-- type = "password" : oculta os caracteres digitados-- type = "email" ou "number" : valida dados especificos-- type = "checkbox " ou "radio" : caixas de marcação e escolha unica. ***type é uma tag que não precisa de fechamento.

<select> : criar uma caixa de seleção em formato de linha suspensa(dropdown)

<textarea> : criar uma caixa com varias linhas, serve para textos longos, comentarios, mensagens e biografias.
